💡 How It Works

  1. Create Pending Circle: Start with just email addresses - no wallets needed yet!
  2. Member Onboarding: As each member signs up, their email gets mapped to their wallet address
  3. Migration: Once all members have wallets, the circle moves on-chain and becomes fully functional
  4. Normal Operation: The circle then works like any traditional blockchain-based saving circle

🔗 Web3 Wallet Integration

This demo works with MetaMask, but the system is designed to integrate with:

  • Privy: Email and social login with embedded wallets
  • MetaMask: Traditional browser wallet extension
  • WalletConnect: Mobile wallet integration
  • Smart Wallets: Account abstraction solutions

Note: This is a demo interface. In production, you'd integrate with Privy for seamless email-based wallet creation and handle the email-to-address mapping automatically during user onboarding.
